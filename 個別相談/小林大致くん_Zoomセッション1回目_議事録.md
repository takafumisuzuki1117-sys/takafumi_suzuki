# エグゼクティブサマリ

1. **この1ヶ月で、チェックの動きと声に変化が出ている。** 大致くん本人も「チェックの動きができるようになってきた」と実感。鈴木からも、スローインの受け方と、相手の見えないところから受けに行く動きが上手になったと伝えた。声かけも「ライン（上げろ）」「寄せろ」「連動しろ」と、試合中にできたと本人が回答。1つ上の学年の試合で、大致くんのサイドが攻撃の起点になっていた。
2. **今回いちばんのメッセージは「1対1は、どんどん仕掛けていい」。** 左足で20〜30mのクロスを無理に上げるより、仕掛けたほうが選択肢が増える場面があった。「抜けなくても、何回でもチャレンジしていい」と伝えた。お父様も同じ考えで、「失敗を考えずに、どんどん仕掛けてほしい」。
3. **仕掛けとクロスの質を上げるコツを、具体的に3つ伝えた。** ①相手に向かうのではなく、スペースに向かって運ぶ（左足のクロスも、切り返して右足のクロスもできる状態をつくる）②ペナルティエリアの中で抜いたら、相手の前に体を入れる（相手はファウルするしかなくなる）③走っている味方へのクロスは、人ではなく前のスペースに置く（空いていればゴロでいい）。
4. **声は「次の段階」へ。** 欲しいところを手で示す、大きな声で呼ぶ、その場で伝えられないことは試合前・ハーフタイム・給水のときに伝える。仲の良い右サイドの5年生には、試合前に「右足で蹴れるときは開いておいて」と伝えることを、本人が「できそう」と答えた。お父様の期待は「**カメラで拾えるくらいの声**」。
5. **次のチャレンジは、大致くんが自分で決めた。** 「動きながらのチェックの動きをやってみたい」。鈴木からは、味方がボールを持つ前に次のプレーを予測して、先に動き出すことが鍵だと伝えた。
6. **お父様の依頼「視野と選択肢」にも手応えがある。** 逆サイドへの展開の場面では、本人がシートに「パスとドリブル、2つの選択肢を持てた」と書いていた。逆サイドもよく見えている。チェックシートの「事前に決めたプラン」の項目は、このように選択肢を2つ、3つ持つことを促すものだと、お父様に説明した。
7. **お父様の満足度は高い。** 「ドリブルもパスも守備もやって、見ていて楽しい」「自分で目標を立てて、小さな段階を一つずつクリアしている。焦らず見守りたい」。フロンターレのスクールでクラスが1つ上がったという報告もあった。

## 3. 動画の振り返り（9:44〜1:03:00）

### 3-1. 1対1の仕掛けと、左足のクロス（9:44／30:59）

**場面：左サイドで1対1になり、左足でクロスを上げた（本人が「クロスを上げるにはどうしたらいいか」と挙げた場面と、それに似た場面）**

- 大致くんの狙い：中の選手まで通したかった。他の選択肢を聞くと、別の味方へのパスやフェイントを本人が挙げた
- 鈴木から：左足で20〜30mの浮き球を中の選手に届けるのは、かなり大変。右足ならこの距離は問題なく蹴れる
- **1対1なら、どんどん抜きに行っていい。** 抜いたあとの選択肢が増える（切り返して右足でクロス／中に切り込んでシュート／縦に運んでインサイドで左足のゴロのパス／後ろの選手に預けてクロスを上げさせる）
- 大事なのは、**一番ゴールにつながりやすいプレーを選ぶこと**。左足のクロスが悪いわけではない
- 大致くん：「抜いてもよかった」
- お父様から：1つ上の学年との試合で、立ち上がりはチーム全体が受けに回ってしまうところがある。試合を通して見ると、マッチアップしている相手には全然負けていない。**試合の入り方**も学んでほしい
- 鈴木から：始まったばかりのときこそ、得意なプレーで1回チャレンジしてみる。「この相手は抜けない」と分かったら、クロスや後ろへのパスに切り替えればいい

**場面：どうやったらクロスを上げきれたか（30:59）**

- 大致くん：一つ前のタッチで切り返して、右足でクロスを上げられた
- 鈴木から：そのとおり。体の動きを見ると、それをやろうとしていたように見えた。ボールのコントロールが少し相手寄りに行ってしまった
- **ドリブルのコースの工夫**：相手に向かって運ぶのではなく、スペースに向かってまっすぐ運ぶ。相手が寄せてこなければ左足でクロス、食いついてきたら切り返して右足でクロス、の両方ができる状態を保つ
- 最終的にはキックまで持ち込めているので、ナイスプレー

### 3-2. ペナルティエリアの中での駆け引き（19:55）

- 切り返して相手を抜いたあと、パスを狙った場面
- 鈴木から大致くんへの問いかけ：ペナルティエリアの中で守るとき、何を考える？ → クリアする、中に行かせない、クロスを上げさせない。ファウルをしたら？ → PKになる
- だから守備側は、エリアの中では飛び込んでこられない
- **抜いた相手の前に体を入れると、相手はファウルするしかなくなる。** そうすれば右足でシュートが打てた
- パスを選んだこと自体は選択肢の一つとしてあり。そのうえで、**相手が嫌がることをやる「ずる賢さ」**を意識すると、できるプレーが増える

### 3-3. シュート（25:04／51:00ごろ）

- 左足でのシュートの場面：大致くんはシュートを選択し、他の選択肢も少し見えていた。**左足でしっかりミートできていた。** もう少しサイドネット寄りなら入っていたかもしれない。自分で決めたプレーなので、あとは決めきる
- 決めきれたらよかった場面：どこに打つといいかを本人に聞くと、「キーパーの上とか、股とか」と、前に話したことを覚えていた
- 鈴木から：キーパーが手で触れる高さは避ける（ファインセーブに見えるが、実は取りやすい位置）。ゴロか上を狙う。左足で上が難しければ、速いゴロ
- キックは練習を重ねれば狙ったところに蹴れるようになる。**いいところまで来ている**

### 3-4. 走っている味方へのクロス（28:03）

- 大致くんは、走っている味方を狙って蹴った
- 鈴木から：**走っている人に向かって蹴ると、ボールは後ろにずれる。人ではなく、前のスペースに置く**
- この場面では、相手も味方もいない大きなスペースが見えていたはず。浮き球でなくていい。ゴロで転がしてあげる
- 強さと狙う場所は、やりながらつかんでいく

### 3-5. チェックの動きで受けた場面（30:14）

- 本人が「意識している」と話していたチェックの動き。ちょっと逆に行くと見せて受け、**相手は完全に見失っていた。** すごく上手になった
- ダイレクトで戻したが、実はフリーだった。前を向いて自分で仕掛けられた
- 試合中に気づけたら一番いいが、まずは振り返りのときに「フリーだったな」「ターンできたかも」と探してみる

### 3-6. 味方を動かす（38:00〜／44:00〜／1:00:10）

**味方にもっと開いていてほしかった場面**

- 大致くん：逆サイドの味方に、もっと外に開いていてほしかった。チームとしても「逆サイドは開いておく」という決まり事がある
- 鈴木から：プレー中の一瞬で味方を動かすのは難しい。では、開いておいてもらうために何ができる？
- 大致くん：「**試合前に言っておく**」「できそう」
- 鈴木から：試合前や試合後、ハーフタイム、給水、セットプレーなど、話せる時間に「右足で蹴れるときは開いておいて。蹴るから」と伝える。**ワンプレーのあとに修正できるかが大事**
- お父様から：右サイドの子は5年生で、チームで一番仲がいい子。前日にチームのコーチと話したとき、この試合ではその子が中に入りすぎていたという話になった。仲がいいから言いやすいはず。試合の中でみんなが声を出せるようになれば、もっと強くなる

**欲しいところにパスを要求したかった場面**

- 大致くんは外に開いて、強いボールが欲しかった。味方は足元に出した
- 大致くんは「分からない」。お父様から：家でこの場面を選ぶときは、どういう意図でプレーしていたかを自分で一生懸命説明していた
- 鈴木から：ボールを持っている味方が顔を上げてこちらを見ているときは、**手で欲しい場所を指してあげる**。声だけでなく手でも見せる。ただし、マークされているときは相手にもばれるので、使い分ける

**フリーだったのにボールが来なかった場面（味方がシュートを打った）**

- 大致くん：「呼べば」受けられた
- 鈴木から：そのとおり。声が入っていなかったので、**大きな声で呼ぶ**。もらえれば仕掛けられる自信があったはずなので、積極的に呼んでいい

### 3-7. 逆サイドへの展開（55:35）

- 本人がシートに「選択肢を2つ持てた」と書いていた場面。もう一つの選択肢はドリブルで運ぶことだった

- 守備の切り替え（50:00ごろ）：ボールを奪われたあと、すぐに切り替えて取り返した。攻撃だけでなく守備も大事

## 4. 大致くんの振り返りと、次のチャレンジ（1:03:00〜1:06:16）

- 大致くん：「**動きながらのチェックの動きをやってみたい**」
- 鈴木から：この試合では、スローイン以外でそういうシーンはまだなかった。動きながらのチェックには、次の2つが必要
  - 味方と目を合わせる
  - **味方がボールを受ける前に、次のプレーを予測して動き始める**
- 例：手で要求した場面も、もっと早く受けられる場所に気づいてダッシュで外に開いていれば、前向きの姿勢で裏を取りながら呼べた
- 次のプレー、その次のプレーを予測できるようになると、もっとフリーで、もっと多くボールを受けられるようになる

## 5. 鈴木からのまとめ（1:06:17〜1:08:07）

1. **1対1は、どんどん仕掛ける。** 相手のほうが上手くても強くても、抜けなくても、何回でもチャレンジしていい。試合でチャレンジしないと、できるようにはならない。仕掛けるときは、スペースへのドリブル、抜いたあとに相手の前に体を入れる
2. **左足のクロスは、人だけでなくスペースに置く**
3. 録画はあとで送るので、もう一度見て、仕掛けるイメージを持ってほしい

# 所感（社内用）

**セットアップで立てた筋「見る → 選ぶ → 伝える」が、1回目でそのまま形になりました。** 大致くんの次のテーマ「動きながらのチェック」は「見る（予測する）」、仕掛けとクロスの判断は「選ぶ」、手で示す・大きな声で呼ぶ・試合前に伝えるは「伝える」です。次の1ヶ月は、**予測して先に動く → 手と声で要求する → 受けたら仕掛ける**という一続きの流れとして伝えると、別々の宿題に見えず、本人も覚えやすくなります。

**お父様の「視野が狭いのか」への答え合わせの材料も、一つ出ています。** 逆サイドの4番を見て展開し、パスとドリブルの2つの選択肢を持てていました。視野そのものより、「受ける前の予測」と「味方を動かす声」が次の伸びしろです。チームのコーチの評価にも、この切り口なら角を立てずに答えられます。

**伝えた論点は、小4には多めでした。** 仕掛け、ドリブルのコース、エリア内で体を入れる、スペースへのクロス、手での要求、声、試合前の伝達、シュートコース、予測。最後のまとめで2つに絞れたのは良かったので、週間チェックインでも2つに絞って続けたいところです。

**大致くんは、Zoomの中では言葉が短めでした**（「ない」「分からない」）。ただ、お父様によると、家で場面を選ぶときは意図をしっかり説明していたそうです。次回は、シートに書いてきたコメントを鈴木が先に読み上げ、「ここは◯◯って書いてくれたよね。そのとき何が見えてた？」と、本人の言葉から入ると話しやすくなります。答えに詰まったときは、「AとBならどっち？」の2択にするのも有効です。
