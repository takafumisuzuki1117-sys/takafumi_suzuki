### ④ お父さんとの対話（20分）

**最初に前半を振り返る（3分）**
- 「今の〇〇くんとのやりとり、見ていてどうでしたか？ 普段と違うところはありましたか？」
- そのあとで、コーチが意識してやっていたことを種明かしする：良かったところから入る／「何が見えてた？」と聞く／答えは言わない／1つだけ伝える／最後は本人の言葉で締める

**聞くこと（上から順に）**
1. 「普段、試合のあとってどんな会話をされていますか？」
2. 「『気負わずがんばってほしい』と書かれていましたが、気負っているように見える場面はありますか？」
3. 「9月のセレクションが終わって、本人の様子はどうですか？」→ **結果はお父さんから話してくれるまで深追いしない**
4. 「6年生の試合での『試行錯誤』って、お父さんから見てどんなところですか？」
5. 「出張先から映像で話すとして、どれくらいの頻度と時間なら続けられそうですか？」

**伝えること（3つ）**

1. **「陰ながら見守る」は、今のままで大丈夫です。** 映像の振り返りでも、お父さんは**質問して聞く役**に徹する。技術や戦術を指摘するのはチームのコーチの役割、と分けておくと、親子の会話が反省会にならない
2. **お父さんが大事にしている3つは、映像の振り返りでそのまま育てられます。**
   - 自分で判断する → 「何が見えて、どう決めた？」と聞く。親が正解を言ってしまうと、それは親の判断になる
   - コミュニケーション → 自分のプレーを言葉で説明することは、ピッチで味方に伝える練習にもなる
   - 楽しむ → 良かったプレーから始める。短く終わる。どのプレーを見るかは本人が選ぶ
3. **6年生の試合とトレセンの差は、伸びしろです。** 結果より「何を試したか」を見てあげてほしい

**セレクションの話になったら**
- 合格した・続けて参加する場合 → 新しい環境でも「自分で判断する」「声を出す」がテーマになる、と今日の話につなげる
- 不合格・結果待ちの場合 → 結果より「当日、何を試せたか」を本人と話す。次の機会まで、どう伸びていくかを一緒に見ていく

### ⑤ まとめ・次の一歩（10分）

- 今日決まったことを確認する：〇〇くんの「次に試すこと」／振り返りのやり方（下の【持ち帰り】）／1回目をいつやるか（例：次の試合の翌日）
- フォローの提案（押しつけない。※どこまで提供するかは要検討）
  - 「最初の2〜3回は、振り返りで迷ったことや〇〇くんが選んだ場面をLINEで送ってもらえれば、ひと言コメントします」
  - 「1〜2か月後に、またここで一緒に映像を見る回をつくっても良いですね。成長を確認する場として」
  - 継続相談の案内は、お父さんの反応を見てから

### 【持ち帰り】おうちでワンプレー振り返り

| | やり方 |
|---|---|
| **いつ** | 週1回、10分以内。試合当日の帰り道は避けて、翌日以降の落ち着いた時間に |
| **何を** | 1〜2プレーだけ。**選ぶのは本人**（慣れてきたら「良かったプレー1つ＋気になるプレー1つ」） |
| **出張先から** | 本人が時間（例：13:40）をLINEで送る → お父さんは先に見ておく → ビデオ通話で一緒に再生する |

**5つの質問**
1. どの場面を選んだ？ なんでそこにした？
2. ボールが来る前、何が見えてた？
3. なんでそのプレーを選んだ？
4. ほかにできそうだったことは？

- チームの監督やコーチの指示と違うことは言わない（迷ったら「コーチに聞いてみよう」で良い）
- 最後は本人の言葉で締める。⑤の答えはLINEに残しておき、次回は「やってみた？」から始める

## 5. 想定される質問と答え方

| 質問 | 答え方 |
|---|---|
| 6年生の試合に出るのは、本人にとってプラスですか？ | 速さや強さの中で「準備」の大切さを体で学べる、貴重な場。ただ、うまくいかない経験が続くと自信をなくすこともあるので、4年生の試合やトレセンなど「できる場」とのバランスで見る。家では「できたか」より「試したか」を聞く |
| セレクションの結果に、どう声をかければ？ | 結果の良し悪しより、当日のチャレンジを本人に言葉にしてもらう。「どんなプレーが出せた？」「次までに何を伸ばしたい？」。親が落ち込みすぎたり、はしゃぎすぎたりしない |
| 親はどこまで口を出していい？ | 技術や戦術の「指摘」はコーチの役割。親は「質問する」「聞く」。本人から「どうしたらいい？」と聞かれたときは、一緒に考えてOK |
| チームとトレセンで言われることが違うときは？ | 親はどちらが正しいかを評価しない。「どっちもやってみて、自分に合うのはどっち？」と本人に判断させる。迷ったら指導者に直接聞かせる。それもコミュニケーションの練習になる |
| 家で何を練習すればいい？ | 映像で見つかった課題（例：首振り）につながる練習を、本人と決める。やらせるより、本人が決めたことを応援する |
| 物おじせず声を出せるようになるには？ | 学年が上のチームで声を出すのはハードルが高い。まずは「ちょうだい」「フリー」などの短いひと言から。映像で声を出していた場面を見つけて褒める |

## 6. やらないこと

- 映像をダメ出しから始める
- 〇〇くんの前で、お父さんに評価を求めたり、他の選手と比べたりする

- チームの監督やコーチの起用・指導を否定する
- 伝えるポイントを2つ以上にする
- 自分の仮説（課題）を決めつけて、そこへ誘導する（本人の言葉を優先する）
