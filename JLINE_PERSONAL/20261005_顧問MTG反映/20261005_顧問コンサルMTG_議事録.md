## エグゼクティブサマリー

1. **YouTube運用は健全。方向性は変えず、週1投稿を継続**
   - CTR5〜6%台は、立ち上げ期のチャンネルとして十分な水準
   - 視聴者層（男性84.1%、35歳以上が中心＝サッカー少年の親世代）は狙い通り
   - テクニック系には寄せず、今の路線に振り切る
2. **AI編集（Claude）は使えるレベル。冒頭フックを強化して投稿テストへ**
   - カット＋テロップを約60分で自動化できた。評価は「70点」で、弱いのは演出（特に冒頭5〜10秒）
   - 視聴維持率が落ちなければ、低コストで回せる手段として継続する
3. **テストローンチは売上30万円。いちばんの課題は「セミナー申込」**
   - LINEリスト430 → 申込23（5.3%）→ 着席12 → 個別相談5 → 成約3
   - 申込は最低50件、理想は100件が目安
4. **商品は「期間」ではなく「内容」で差をつけ、単価を上げる**
   - 動画教材を新しく作り、上位プランを厚くする
   - 期間は同じ6ヶ月のまま、上位プランから要素を減らしたものを下位プランにする
5. **次回ローンチは企画名と見せ方を全面的に変える**
   - 「課題発見ライブセミナー」はハードルが高い → 「サッカーIQ」「Jリーガー」など響く言葉に変える
   - 同じ企画を同じリストに出すと反応ゼロの恐れ。実施までにリストを倍に増やす

## アジェンダ別サマリー

### 【1】YouTubeチャンネルの現状・アナリティクスの見方

**現状**
- 直近の実績：投稿4本、リスト獲得118件
- 週1投稿のうち1週分が抜けた（AIでジャンプカットした素材を外注の編集者に渡したところ「この品質では編集できない」と差し戻され、遅れた）
- 12.6万回再生の動画がある。過去の動画も直近48時間で再生が伸びている
- 大学サッカー部の同期など、サッカー経験のある親世代に認知が広がっている実感がある
- 鈴木の懸念：CTRが低いのでは？（直近動画は5.1%）

**CTRの見方（YouTube Studio）**
- アナリティクス → コンテンツ → 各動画 → 「リーチ」タブでCTRの推移を見る
- 公開直後のCTR（初速）がいちばん高く、インプレッションが増えるにつれて下がるのは正常（例：初速6.5% → 落ち着いた後は6.2%）
- 立ち上げ期は、YouTubeがどこに表示するかを学習している途中なので数値が上下しやすい。規模が大きくなると安定する
- 流入はほぼ「ブラウジング機能」から。関連動画の傾向も参考になる

**コンサル所見**
- 平均で5%を切っていないだけで十分優秀。このジャンルで7〜8%は難しい
- 5.9%前後なら良い方。初速で9%台を何本か出せれば理想
- 直近の「Jリーガーになるために必要な能力」は5.1%だが、上がってきている
- サムネのコピーを磨けばまだ伸ばせる
- 平均視聴時間、リピーター率も良好。「今できることはすべてできている」
- 1本投稿が抜けたのはもったいなかった

**視聴者分析**
- 男性84.1%、35歳以上が中心 → サッカー少年の親世代で、狙い通り
- 「チャンネルの視聴者が視聴している他のチャンネル」は、チャンネルが活発な時期にしか表示されない → 今のうちに全部メモして、ベンチマークや台本ネタに使う

**競合と方向性**
- 大手のテクニック系チャンネルで、鈴木の動画と構成・台本がよく似た動画を見つけた（約4,000回再生、内容は薄い）→ ひどいと思えば通報してよい
- テクニック系の方が再生は取りやすいが、ターゲット外の層が集まりやすい
- 大規模で長く運営しているチャンネルは、マンネリでCTRが落ちたりネタが尽きたりしやすい
- **結論：今の路線（親向け・思考/育成）に振り切ってよい**

### 【2】AI動画編集の検証とフィードバック

**現状**
- Claudeで編集。何本かでプロンプトを磨いた結果、今回は比較的良い仕上がりになった
- 撮影素材から約60分でカット＋テロップまで自動処理、尺は約15分
- 冒頭のフックはまだ入れていない（これから追加する）

**コンサル所見**
- 全体として「70点」くらい。弱いのは演出
- 特に冒頭5〜10秒のオープニングフックをもっと見応えのあるものにしたい（参考：美容・ダイエット系チャンネルの冒頭演出）→ あのレベルは外注に頼むクラスかもしれない
- 効果音は、最悪なくてもよい
- AIに演出を指示するには結局人の手間がかかり、「人が編集した方が早い」という見方もある

**結論**
- 冒頭フックを強化したうえで、AI編集版で一度投稿してみる
- 視聴維持率などが落ちなければ、そのまま続けてよい
- まだ投資を回収できていない段階なので、コストを抑えて続けることを優先する

### 【3】テストローンチの結果

**ファネル実績**

| 段階 | 人数 | 率 |
|---|---|---|
| 公式LINEリスト | 430名 | ― |
| セミナー申込 | 23名 | 申込率 5.3% |
| セミナー着席 | 12名 | 着席率 52% |
| 個別相談 | 5名 | 個別相談率 42% |
| 成約 | 3名 | 成約率 60%／売上 30万円 |

**補足（鈴木）**
- セミナー1回目（着席5名）は内容が不十分で、個別相談は0名。2回目（7名）から5名が個別相談に来た
- 個別相談の5名のうち2名は「売らない方がいい」と判断した → 個別相談まで来てもらえれば、売りたい人には売れる手応えがある

**コンサル所見**
- 最大の課題はセミナー申込。最低50件、理想は100件
- 着席率は70〜80%（75%前後）が目安 → 今の約50%は低い
- 個別相談への誘導率40%台は一般的だが、少人数のセミナーならもっと上げたい
- 試算：申込が約2倍になれば売上は約60万円、さらに単価を1.5倍にすれば約90万円

### 【4】商品設計・価格の見直し

**コンサル提案**
1. 動画教材を作る（個別相談でよく出る質問を動画化。買った時点で手に入るものができ、サポートも楽になる）
2. 期間ではなく「内容」で差をつける（月あたりの単価が同じだと「まず短い方で試す」になり上位が売れない）
3. まず上位プランだけを見せ、「厳しい」と言われたら下位プランを提案する
4. 単価を上げる（今の価格は個別相談で売る単価としては安すぎる）
5. 投資した分のリターンをセミナーで伝える（子どもへの支出は自己投資と違い、リターンが見えにくい）

**鈴木の気づき**
- 面談した保護者から「サッカー以外にも役立ちそう」という反応があった → 「将来に生きる力」として伝える形でセミナーに組み込む

### 【5】次回ローンチの企画（10月末〜11月頭）

- 同じ企画を同じリストに出しても反応はなく、売上ゼロの可能性がある
- 実施までにリストを倍に増やしたい（鈴木は時期を少し後ろにずらすことも検討）。シーズンから見た時期の適切さも確認する
- 提供内容は同じでよい。変えるのは「企画＝入口の見せ方」
- 「課題発見ライブセミナー」は長く、求めるリテラシーが高すぎる
- YouTubeで反応が良い言葉（Jリーガー、サッカーIQ、育成、才能開花など）を企画に使う。「Jリーガーにします」と約束する必要はない
- 課題発見の大切さは、セミナーの中で伝えればよい
