## 2. MTGで指摘されたこと

1. **期間で差をつけると、上位が売れない**：違いが期間だけだと「まず短い方で試して、良ければ延長」になる
2. **単価が安い**：6万円・12万円は、個別相談で時間をかけて売る単価ではない
3. **期間はそろえて、中身で差をつける**：上位プランから要素を抜いたものを下位プランにする（松から何かを減らして竹にする）
4. **動画教材をつける**：買った時点で手に入るものができ、毎回同じ質問に答えなくて済む
5. **上位プランだけを先に見せる**：「厳しい」と言われたら、下位プランを「この形もある」と出す
6. **投資のリターンを伝える**：子どもへの支出は自己投資と違い、何が返ってくるかが見えにくい

### この形にした理由

- **期間が同じなので、月額で比べられない**：比べるのは「毎週か、隔週か」だけになる
- **下位プランへの下げ方に、無理がない**：「毎週の動画提出は、ご家庭によっては負担が大きい」という理由で隔週を出せる。お金の話だけで値下げする形にならない（v3.0で書いた「提出の負担」の論点をそのまま使える）
- **プレミアムの価格は、v3.0のインテンシブ6ヶ月（240,000円）と同じ**。スタンダードもv3.0のスタンダード6ヶ月（150,000円）とほぼ同じで、これまでの検討とつながっている
- **保護者面談は、v2.0で書いた「経路B（親の関わり方が変わる）」の装置**。プレミアムにだけ入れて、上位の価値をはっきりさせる

### オプション単価で換算した場合（提案資料に載せる「相当額」）

|---|---|---|
| プレミアム | Zoom 12回×15,000円＋動画解説 12回×10,000円＋保護者面談 2回×15,000円 | **330,000円相当＋動画講座** → 240,000円 |
| スタンダード | Zoom 6回×15,000円＋動画解説 6回×10,000円 | **150,000円相当＋動画講座** → 148,000円 |

### 3ヶ月プランとZoom集中の扱い

- **メニューからは外す**。期間で比べる構図に戻らないようにするため
- 相談で「3ヶ月だけ」と言われたら：「3ヶ月だと型は入りますが、自分で回すところまでは行き切りません」（v2.0の答え方）
- 例外：セレクション直前など、時期が決まっている場合だけ、相談の場で個別に見積もる
- Zoom集中（60,000円）は既存の方のみ。新規には出さない

## 5. 個別相談での提示トーク（ワンプレー相談 v2.1 の提案パートを差し替え）

### 流れ

1. 無料で約束したこと（次の試合で試す1テーマ）を渡しきる
2. 「合いそうなサポートがあるので、5分だけ」と断ってから話す
3. **プレミアムだけ**を説明する（中身 → 到達点 → 価格）。価格を言ったら、相手が話すまで待つ
4. 「厳しい」と言われたら、**提出の負担**を理由にスタンダードを出す
5. その場で決まらなければ、既存のフォロー（②検討状況の確認・3〜4日後）に戻す

### セリフ

**② 切り出し**

ここまでで、今日お約束した「次の試合で試すこと」は決まりました。

そのうえで、◯◯くんに合いそうなサポートがあるので、5分だけお時間をいただいてもいいですか？

**③ プレミアムの説明**

僕がおすすめしたいのは、プレミアムという6ヶ月のプランです。

毎週、◯◯くんの試合を一緒に見ます。月2回のZoomと、月2回の動画解説で、毎試合の答え合わせをする形です。

最初の2ヶ月は僕が全部示して、次の2ヶ月は◯◯くんが先に見立てを出して、最後の2ヶ月は自分で回す。6ヶ月で、コーチがいなくても振り返れる状態まで持っていきます。

3ヶ月に1回、親御さんとだけ話す時間もあります。家での声のかけ方や、進路のこともここでご相談いただけます。

最初に、試合動画の撮り方や見方をまとめた動画講座もお渡しします。

料金は、6ヶ月で24万円（税別）です。月あたり4万円になります。

（ここで黙る。相手が口を開くまで待つ）

**③-2 投資のリターン（迷いが見えたとき）**

お子さんのサッカーには、もうたくさんの時間とお金をかけていらっしゃると思います。

これは、その努力の方向を合わせるためのものです。

そして、ここで身につく「自分で見て、考えて、修正する力」は、サッカーを続けても、辞めても残ります。

**④ 「厳しい」と言われたら**

正直に言っていただいて、ありがとうございます。

実は、毎週動画を送るのは、ご家庭によっては負担が大きいんです。撮影して、切り出して、送る。それが毎週になるので。

なので、隔週の形もあります。

期間は同じ6ヶ月で、Zoomと動画解説が月1回ずつになります。動画講座は同じものをお渡しします。

こちらは6ヶ月で14万8千円（税別）、月あたり約2万5千円です。

6ヶ月で自分で回せる状態を目指すのは同じです。違うのは、答え合わせの回数と、親御さんとの面談があるかどうかだけです。

### やらないこと

- 最初から2つのプランを並べて見せない（安い方を選ぶための比較になる）
- 3ヶ月プランを自分から出さない
- 「今だけ」「残りわずか」は、本当にそうな時だけ言う（新規枠が残り4名なのは事実なので、その範囲で伝える）
