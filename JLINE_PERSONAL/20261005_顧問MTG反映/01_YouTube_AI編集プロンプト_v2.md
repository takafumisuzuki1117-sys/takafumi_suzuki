# YouTube AI編集プロンプト v2（冒頭フック・演出強化版）

- 作成：2026-10-05
- 対象：17本目以降（「首を振れ」回から適用）
- 反映元：顧問コンサルMTG（2026-10-05）／もえぞう式勉強会資料（2026-09-24）／16本目の編集指示書（2026-09-30）

---

## 1. この版で変わったこと

| | v1（16本目まで） | v2（17本目から） |
|---|---|---|
| 評価 | カット・テロップは合格。全体で「70点」 | 弱点の「演出」、特に冒頭5〜10秒を強化 |
| 冒頭 | 話し手の映像＋テロップ | 最初の一言は「文字が主役」の全画面カード。5〜10秒以内に必ず画変わり |
| 演出の決め方 | 編集のたびにAIへ指示（指示に時間がかかる） | 台本を書く段階で【演出タグ】を入れ、編集AIはそれを実行するだけ |
| 効果音 | 外注で都度 | 必須はロゴとモノクロの2種だけ。それ以外は任意 |
| 続けるかの判断 | ― | 視聴維持率（30秒・1分・5分）が外注回の平均を下回らなければ継続 |

**MTGでの指摘と、それへの答え**

| 指摘 | v2での対応 |
|---|---|
| 演出が弱い（70点） | 冒頭と本編に「画変わり」「カード化」のルールを数値で入れた（§3） |
| 冒頭5〜10秒をもっとリッチに | 最初の一言を全画面カードにし、対比カード・寄りで5秒ごとに画を変える（§3の1） |
| 演出をAIに指示すると、結局人と同じ時間がかかる | 指示は台本作成時にまとめて済ませる（§4の演出タグ）。編集時の指示はゼロにする |
| 効果音は最悪なくていい | 必須を2種に絞り、外注の手間を減らす（§3の3） |
| 維持率が落ちなければAIで続けていい | 公開7日後に数字を記入する表を用意（§6） |

## 2. 使い方

1. **台本を作るとき**：§4の「演出タグ」を、台本作成プロンプト（としぞうくんPro／台本ナレッジ）の末尾に貼っておく。以後の台本には自動でタグが入る
2. **撮影後**：撮影データ＋台本（タグ入り）＋§3のプロンプトをClaudeに渡す
   - 既存の編集プロンプトがある場合は、§3の「v2で追加する指示」だけを末尾に貼ればOK（既存の仕様は変えない）
3. **書き出し後**：プロンプト内の「書き出し前チェック」で確認 → 花澤さんへ指示書と一緒に納品（ロゴ・BGM・効果音・アップロード）
4. **公開7日後**：§6の表に数字を記入し、AI編集を続けるか判断する

## 3. 編集プロンプト（そのまま貼る）

```text
あなたは「考える力を育てるサッカーch（鈴木崇文）」の動画編集担当です。
撮影データと台本をもとに、YouTube本編（横型16:9）を編集してください。

# 視聴者と目的
- 視聴者：サッカーをする小中学生の保護者（男性84%、35歳以上が中心）
- 目的：初めて見る人を冒頭で離脱させず、中間CTA（公式LINE）まで見てもらうこと
- 何で評価するか：視聴維持率（30秒時点・1分時点・5分時点）

# 既存の仕様（変更なし）
- 全体を1.15倍速（音程は維持）
- ネガティブな断定の瞬間は、モノクロ＋強めのコントラスト（台本の【モノクロ】、またはネガティブな断定）
- 重要語は黄色帯テロップ。図解・カード・出典表示を入れる
- 左上にJLINEロゴのバッジ
- 声は -14 LUFS／トゥルーピーク -1.5dB
- 納品物：映像の土台／図解・カード（透過）／テロップ（透過）の3レイヤー、Premiere XML、完成見本（タイムコード入りを含む）、声のみのwav、指示書
- 書き出し：1920×1080／30fps／H.264 High／CRF17相当／yuv420p／bt709／AAC 320kbps／faststart

# v2で追加する指示

## 1. オープニング（0:00〜0:45）
ねらい：最初の5秒で「うちの子の話だ」と思わせ、できるだけ早く「今日は何の話か」まで伝える（もえぞう式の目安：タイトルコールまで20秒以内）。

(1) 第一声より前の無音・息継ぎ・「えー」は、0フレームまで詰める。

(2) フック（台本の【OP】冒頭〜「皆さんこんにちは」の直前。目安5〜10秒）
  - 最初の一言は、話し手の映像ではなく「全画面の文字カード」で見せる
    ・濃紺〜黒の背景に、白の太字を中央に配置。1行8〜12字、最大2行
    ・強調語だけ黄色。声に合わせて0.6〜1.2秒表示する
    ・台本に【フックカード：〜】があれば、その文言を使う
  - 続く2〜3行は、話し手の寄り（1.2倍前後）＋大きめの中央テロップ（通常テロップの1.3倍）
  - 台本に【フック映像：〜】があれば、その素材を背景に敷き、暗く落として文字を読ませる
  - 「AではなくB」という対比は、Aに打ち消し線、Bを黄色にした対比カードで見せる
  - 最初の5〜10秒の間に、少なくとも1回は画変わり（カード⇔話し手、寄り⇔引き）を入れる

(3) 名乗り（「皆さんこんにちは」〜実績）
  - 話し手を通常サイズに戻す（ここで画変わり）
  - 画面下に肩書きテロップを出す：「元Jリーガー 鈴木崇文｜プロ9年・通算224試合」
  - 言い淀みや長い間は詰める（台本の文言そのものは削らない）

(4) テーマ提示（「今日は〜をお話しします」）
  - 動画タイトルを要約した「テーマカード」を1.5秒入れる（台本に【テーマカード：〜】があればその文言）

(5) ベネフィット〜「ぜひ最後までご覧ください！」
  - 「〜が分かる」の部分を、チェック付きの箇条テロップで2つまで出す
  - OP全体は40秒前後、最長50秒。超えそうなら言い直しや重複をカットする。
    台本の文言そのものは勝手に削らず、削る候補を指示書に書く

(6) 台本に【チラ見せ：〜】があれば、OP直後（ロゴインサートの後）に結論テロップを3秒先出しする

## 2. 本編（少しずつ離脱されるのを防ぐ）
- 同じ画角を15秒以上続けない。通常サイズと寄り（1.15〜1.25倍）を交互に使う
- 強調のセリフ（「ここがすごく大事です」「断言します」「結論から言います」など）と台本の【寄り】では必ず寄る
- 台本の【画面：〜】【図解：〜】は必ず実装する。指示がなくても、次の3つはカードにする
  ・数字（〇回、〇秒、〇%、〇試合）
  ・「1つ目・2つ目」の列挙
  ・STEP・章の見出し
- 章が変わる所（【STEP】【番外編】【自己流の限界】など）には、章タイトルカードを1.2〜1.5秒入れる。
  タイムコードを指示書の「章の区切り」と「BGM切り替え候補」に載せる
- テロップは出しっぱなしにしない。ポップイン（0.15秒ほどで拡大→等倍）で出す
- 中間CTA（「と、ここで一つ重要な話があって」以降）
  ・暗くしない。明るめのトーンで「見どころ」として見せる
  ・特典（動画分析チェックシート）の実物画像を画面右側に出し、「概要欄から受け取れます」の矢印テロップを入れる（台本の【特典表示】のタイミング）
  ・CTAの間はモノクロを使わない
- 番外編は「番外編」カードで区切り、「本題に戻ります」の所でもう一度カードを入れる

## 3. 効果音
- 必須：①JLINEロゴのインサート ②モノクロの始まり（「シャン」系）
- 任意：全画面フックカード、章タイトルカード（軽いポップ音）
- それ以外は入れなくてよい。入れる場合も声より大きくしない

## 4. 指示書に追加で書くもの
- 「OPの設計表」：0:00〜OP終了までの、タイムコード／セリフ／画面／テロップ／音
- 「最初の60秒の画変わり一覧」
- 「章の区切り」と「BGM切り替え候補」のタイムコード
- 「OPが50秒を超えた場合のカット候補」
- 書き出し前チェック（下記）の○×

## 5. 書き出し前チェック
- 第一声の前に無音がない
- 最初の5〜10秒の間に画変わりがある
- 冒頭の重要語がすぐテロップになっている
- 「えー」「あのー」が残っていない
- OPが50秒以内
- 同じ画角が15秒以上続く所がない
- 数字・列挙・STEPがカードになっている
- 中間CTAで特典画像が出ている
- スマホの標準音量で声が聞き取りやすく、BGMが声を邪魔していない
```

## 4. 台本作成プロンプトへの追記ブロック（演出タグ）

MTGで「演出をAIにやらせるには、誰かが指示しないといけない」という話がありました。その指示を、**台本を書く時点でまとめて済ませる**ためのブロックです。台本作成プロンプト（としぞうくんPro／台本ナレッジ）の末尾に貼ってください。

```text
# 台本に入れる演出タグ
編集AIへの指示を、台本の段階で済ませるためのタグです。
該当する行の直前に入れてください。タグは読み上げません。

【フックカード：〜】 冒頭の全画面文字カードに出す言葉（1行8〜12字、最大2行）
【フック映像：〜】 フックの背景に使う素材（自分の試合映像・練習風景など。受講生の映像は、本人と保護者の許可があるものだけ）
【テーマカード：〜】 動画タイトルを要約した言葉（15字以内）
【チラ見せ：〜】 OP直後に先出しする結論（20字以内）
【寄り】 このセリフで話し手に寄る
【図解：〜】 図解・カードにする内容
【モノクロ】 ネガティブな断定（既存ルール）
【特典表示】 中間CTAで特典画像を出すタイミング

# OPの型（30〜40秒、最長50秒）
1. 導入フック（5〜10秒）：視聴者の悩みの場面を一言で。反常識・対比で始める。1行目には必ず【フックカード】を付ける
2. 名乗り
3. タイトルコール：「今日は〜をお話しします」（フックからここまでで20秒以内が目安）
4. 視聴者の悩みや叶えたいことを1つだけ言う（他の動画にも使い回せる抽象的な内容なら入れない）
5. この動画で分かること →「ぜひ最後までご覧ください！」
6. OP直後に、本題の結論を一言だけ先に言う（【チラ見せ】を付ける）
```

### 名乗りの短縮（任意・テスト）

もえぞう式の型では、フック〜名乗り〜タイトルコールまでを20秒以内に収めるのが目安です。今の統一版の名乗りは約105字（台本の尺計算〈430字/分〉で約15秒）あり、フック（5〜10秒）と合わせると、タイトルコールまでに25〜30秒かかります。実績は肩書きテロップで画面に出るので、声では短くする案です。**1本だけ試して、30秒時点の維持率で判断**してください。

| | 文言 | 目安 |
|---|---|---|
| 現行（統一版） | 皆さんこんにちは。元Jリーガーで、サッカーを通じて考える力を育てるパーソナルコーチの鈴木です。僕は元Jリーガーとして9年間、通算224試合に出場し、現在は育成年代の選手にオンラインでパーソナルトレーニングを行っています。 | 約15秒 |
| 短縮版（テスト） | 皆さんこんにちは。元Jリーガーで、サッカーを通じて考える力を育てるパーソナルコーチの鈴木です。 ＋肩書きテロップ「プロ9年・通算224試合／育成年代のオンラインパーソナルコーチ」 | 約7秒 |

## 5. 撮影時のチェック（編集では直せないもの）

- 第一声から口角が上がっている／レンズをまっすぐ見ている
- 顔が明るく均一に照らされている／背景が整っている
- 外付けマイクを使い、エアコンやPCのファンの音が入っていない
- 重要な結論はゆっくり、具体例はテンポよく話している
- 結論の直前に、少し「間」を取っている

## 6. AI編集を続けるかの判断（公開7日後に記入）

YouTube Studio → アナリティクス → 各動画 → エンゲージメント → 「視聴者維持率」で、30秒・1分・5分時点の数字を読みます。

| 本数 | 編集 | 30秒時点 | 1分時点 | 5分時点 | 平均視聴率 | CTR | LINE登録 |
|---|---|---|---|---|---|---|---|
| （外注回①） | 外注 | | | | | | |
| （外注回②） | 外注 | | | | | | |
| 16本目 | AI＋外注（ロゴ・BGM・効果音） | | | | | | |
| 17本目 | AI v2 | | | | | | |
| 18本目 | AI v2 | | | | | | |

※外注回には、全編を外注で編集した直近の2本を入れてください。

**判断基準**
- AI v2の「30秒時点」と「5分時点」の維持率が、外注回の平均を下回らなければ、AI編集で継続
- 5分時点の目標は30〜40%（もえぞう式の基準）
- 下回った場合は、冒頭（0〜30秒）だけ外注し、それ以降をAIで編集する形を試す

## 7. 17本目への適用例（「首を振れ」回）

17本目のOPは318字（430字/分で約44秒）で、型の範囲内です。台本の文言は変えず、演出だけを当てた設計表です。

| 時間（目安） | セリフ | 画面 | テロップ | 音 |
|---|---|---|---|---|
| 0:00〜0:01 | 「首を振れ」 | 全画面フックカード（濃紺の背景） | 首を振れ（白・特大） | ポップ音（任意） |
| 0:01〜0:05 | そう言われて、首も振っている。なのに、試合ではボールが来た瞬間に奪われてしまう。 | 話し手の寄り（1.2倍） | 首は振っている →「なのに**奪われる**」（奪われる＝黄色） | ― |
| 0:05〜0:10 | もしお子さんがこの状態なら、足りないのは、技術ではなく準備かもしれません。 | 引きに戻す（画変わり）→ 対比カード | ~~技術~~ → **準備**（黄色） | ― |
| 0:10〜0:25 | 皆さんこんにちは。元Jリーガーで〜 | 通常サイズ | 肩書きテロップ「元Jリーガー 鈴木崇文｜プロ9年・通算224試合」 | ― |
| 0:25〜0:33 | 今日は、首を振るだけでは周りが見えない理由と〜お話しします。 | テーマカード1.5秒 → 話し手 | 「首を振っても、周りが見えない理由」 | ― |
| 0:33〜0:44 | 練習でできる技術を〜ぜひ最後までご覧ください！ | 寄り | ✓ 首を振る前に確認するもの／✓ 試合後の問いかけ方 | ― |
| 0:44 | ― | JLINEロゴのインサート（花澤さん） | ― | ロゴの効果音 |
| ロゴの後 | （撮影がまだなら追加を推奨）「結論から言うと、首を振ったら、まず『一番近い相手』です。」 | 話し手 | チラ見せ：結論「まず一番近い相手」（3秒） | ― |

**撮影済みの場合**：ロゴの後に、STEP1の「特に小学生のうちは、まず『自分に一番近い相手』を確認できれば十分です」をテロップだけで3秒先出しすれば、撮り直しは不要です。

**モノクロ＋効果音の候補（17本目）**
- 「ただ、回数を増やすだけでは、試合で周りが見えるようにはなりません」
- 「トラップした瞬間に寄せられて、奪われてしまいます」
- 「目を離した瞬間に逆から寄せられる、あの場面が増えてしまうんです」
