## 3. 購入者限定の追加オプション

受講中の方だけが、必要になったときに単発で追加できるものです。

| オプション | 今 | 11月から | 条件 |
|---|---|---|---|
| Zoom追加（60分） | 15,000円 | **18,000円** | 事前に試合動画を確認して実施 |
| 動画解説追加 | 10,000円 | **12,000円** | 提出から3日以内に返却 |
| 保護者面談（60分） | 15,000円 | **18,000円** | 関わり方・進路・困りごとの相談。保護者のみで受講可 |
| 対面トレーニング | 25,000円 | **30,000円** | オンラインで課題を特定してから提案。月2枠まで。東京・神奈川は交通費込み（その他は実費）、施設利用料は別途 |

**値上げする理由**：今のオプション単価のまま月2.5万円にすると、Zoom 15,000円＋動画解説 10,000円＝月25,000円で、プランの価格と同じになります。プランで申し込むお得さがなくなるので、オプションを2割前後上げて、プランの方が月5,000円（6ヶ月で30,000円）お得になる形にしています。

- 金額は10/21に決定
- 対面30,000円は、商品設計v2.0で一度決めていた金額です
- 今受講中の方（小林くん・木村さん・坂本くん）は、しばらく今の金額のまま（10/21決定）

## 5. 相談での出し方

プランが1つなので、「上位から見せる」流れは使いません。追補v1.0の時間配分（60分）と、価格の反論の順番はそのまま使います。

### 流れ

1. 無料で約束したこと（次の試合で試す1テーマ）を渡しきる
2. 「合いそうなサポートがあるので、5分だけ」と断ってから話す
3. 中身 → 到達点 → 価格の順に話す。価格を言ったら、相手が話すまで待つ
4. 「高い」と言われたら、下の順番で返す。値引きはしない
5. その場で決まらなければ、次の接点を「次の試合の翌日」で決める

### セリフ

**中身と価格**

```
僕がおすすめしたいのは、6ヶ月のプランです。

2週間に1回、◯◯くんの試合を一緒に見ます。
月1回のZoomと、月1回の動画解説で、
試合ごとの答え合わせをする形です。

最初の2ヶ月は僕が全部示して、
次の2ヶ月は◯◯くんが先に見立てを出して、
最後の2ヶ月は自分で回す。
6ヶ月で、コーチがいなくても振り返れる状態まで持っていきます。

料金は、6ヶ月で15万円（税別）です。
月あたり2万5千円になります。
```

（ここで黙る。相手が口を開くまで待つ）

**「高い」と言われたら**

```
そうですよね。安い金額ではないと思います。
正直に言っていただいて、助かります。

参考までに、今サッカー以外も含めて、
習い事にはどれくらいかけられていますか？
```

（答えを聞く。出てきた話題に流れない）

```
6ヶ月で15万円なので、月に直すと2万5千円です。

Zoomと動画解説を、受講中に単発で追加すると
1回ずつで月3万円になります。
6ヶ月で通して申し込んでいただく方が、3万円分お得になる形です。

お子さんのサッカーには、もうたくさんの時間とお金を
かけていらっしゃると思います。
これは、その努力の方向を合わせるためのものです。
```

### やらないこと

- 値引きしない。3ヶ月プランを自分から出さない
- 新規の受付人数（「残り◯名」）は言わない（10/21決定）
- プレミアムや動画講座の話はしない
