## 3. トークスクリプト

### ① オープニング（5分）

- **挨拶：**「こんばんは、鈴木崇文です。土曜の夜にありがとうございます。」
- **同席の確認：**「今日はお子さんも一緒ですか？」
  - 同席している → 本人に自己紹介してもらう（名前・学年・ポジション）。以降の質問はなるべく本人に向ける
  - いない → 「大丈夫です。畑山さんから見えている様子を教えてください。」続けて、責めずに「本人は今日のこと知ってます？」と聞く（後で提案するかどうかの判断材料になる）
- **遠慮を外す：**「今日は上手い子のための時間じゃなくて、『今、何を意識すると試合が変わるか』を一緒に整理する時間です。」
- **ゴールと流れ：**「最後に『次の試合で試すことを1つ』決めて終わるのがゴールです。前半でお話を聞いて、真ん中でプレーを一緒に見て、最後に次の一歩を決めます。」
- **提案の許可を先にとる：**「最後に、もし必要そうなら僕のサポートの話を5分だけさせてください。合わなそうなら正直にそう言いますし、今日決めていただく必要もありません。」
- **アイスブレイク（どちらか1つ）：**
  - 「YouTubeから見つけてくださったんですよね。どの動画でした？」
  - 「8/30のLIVE、ご覧になれました？」
    - 見た → 「どこが印象に残りました？」（印象に残った所＝悩みの手がかり）
    - 見ていない → 「準備→判断→技術の順で見る」を1分で説明する

### ② ヒアリング（15分）

**まず事前3問（未回答なのでここで聞く）**

1. お子さんのお名前と学年
2. チーム（部活かクラブか）、ポジション、試合への出場状況
3. 今一番気になっているプレーや場面

**次に深掘り**

| 聞くこと | 質問例 | 聞く理由 |
|---|---|---|
| 直近の試合 | 「今日か明日、試合でした？どうでした？」 | 記憶が新しい場面を診断に使える |
| 本人の目標 | 「本人はこの先どうなりたいって言ってます？」「高校で（新チームで）どうなりたい？」 | 期限と本人のやる気を確かめる。プラン選びに使う |
| 保護者から見た課題 | 「畑山さんから見て、一番もったいないなと思う場面はどこですか？」 | 保護者の見立てを知る |
| 本人が言う課題 | 「本人は自分の課題を何だと言ってます？」 | 親子の見立てのズレを知る |
| 家での会話 | 「試合のあと、家でサッカーの話ってします？アドバイスすると本人はどんな反応ですか？」 | 「分かってる」「今は言わないで」になっていないか（LINE配信の中心テーマ） |
| これまでの取り組み | 「スクールや自主練など、今までどんなことをやってきました？」 | 頑張っているのに結果が出ない状態かを確かめる |
| 申し込んだきっかけ | 「今回、申し込んでみようと思ったきっかけって何かありました？」 | 本当の悩みが出やすい。ここは深掘りする |

> **ポイント：** 返信が少ない方なので、答えやすい質問から入る。「部活ですか？クラブですか？」のように選んでもらう形だと話しやすい。

### ③ プレー診断（20分）

**A. 動画がある場合**（事前に届いた場合、またはその場で送ってもらう）

- 「スマホに試合の動画ありませんか？10秒くらいで大丈夫なので、今LINEかZoomのチャットで送ってもらえれば一緒に見られます。」
- **準備 → 判断 → 技術** の順で見る
  - 準備：「ボールが来る前、どこに立ってた？何が見えてた？体の向きは？」
  - 判断：「なんでそのプレーを選んだ？他にどんな選択肢があった？」
  - 技術：「選んだプレーをやり切れた？」
- 本人がいれば本人に答えてもらう。正解は言わず、「いいね、その見方」と考えたこと自体を認める

**B. 動画がない場合**

- よくある場面を言葉で再現してもらう：「一番多いミスって、どんな場面ですか？どこでボールを受けて、どうなることが多いですか？」
- 必要ならLIVEのサンプル映像を画面共有して同じ見方を体験してもらい、そのあとお子さんの場面に置き換える

**診断のまとめ（必ず3つに絞って伝える）**

- ⚠️ **本当の課題：** 〇〇（技術ではなく準備・判断にあることが多い →「練習を増やす」ではなく「見方を変える」）
- 🎯 **次の試合のテーマ：** 〇〇（「もっと周りを見る」ではなく「受ける前に1回首を振る」のように、行動で決める）

**プランの選び方（ヒアリングの内容で決める）**
- 3ヶ月以内に動かせない期限がある（中3の進路・練習会、高1の新人戦）→ **プレミアム**

- 迷ったらスタンダードをすすめる（推奨プランで、月々の負担も軽い）

**必ず伝えること**

- 動画解説・Zoomの予約は、本人か保護者が自分で行う。「自分で動く」こと自体がサポートの一部
- 動画解説は試合動画のみ（前半か後半をまるごと、引いた画角で）。提出から3日以内に返す
- 分割払いはカード決済のみ。銀行振込は一括

- 試合出場・合格などの成果は保証しない

### ⑥ クロージング（5分）

- まず感想を聞く：「ここまで聞いてみて、どうですか？」（こちらから決断を迫らない）
- **前向きな場合：**「お申し込みページをLINEで送りますね。」→ その場でLINEを送り、一緒に画面を見ながら手順を確認する（分割希望ならカード決済）
- **検討したい場合：**「もちろんです。」と受けて、次の3つを決める
  1. 誰と相談するか
  2. いつまでに決めるか
  3. こちらからいつLINEするか（例：「では火曜の夜にLINEで一言ご連絡しますね」）
  - 予約日を忘れていたこともあるので、相手からの連絡を待たず、こちらから連絡する形にする

**よくある反応と返し方**

| 反応 | 返し方 |
|---|---|
| 「本人と相談してから」 | 「それが一番大事です。本人がやりたいと思わないと続かないので。」→ 今日のまとめをLINEで送る。本人と話す15分のZoomを提案してもよい |
| 「家族と相談してから」 | 今日のまとめとプラン表をLINEで送り、決める日を決める |
| 「金額が…」 | 押さない。カード分割なら月22,000円（スタンダード）、最初の1ヶ月は全額返金があることを事実として伝える |
| 「忙しくて続けられるか」 | 予約や振り返りは本人が中心。保護者の役割は「教える人」から「一番のサポーター」になること。保護者の手間を増やすものではない |
| 「本人がやる気になるか…」 | 「親が言うと届かないことも、第三者から聞かれると本人が考え始めることがあります。」最初の1ヶ月の返金保証も伝える |
| 「チームのコーチがいるので」 | チームの指導とぶつかることはしない。試合の見方と振り返りの習慣をつくるもの |
| 「うちの子はまだそのレベルじゃない」 | 「上手い子のためのものじゃありません。むしろ今の課題が分からない段階のほうが効きます。」 |

**提案しない・見送るケース（正直に伝える）**
- 本人にサッカーを続ける気持ちが見えない、または本人が嫌がっている
- 悩みが体力・スピードなどフィジカル中心で、試合の見方や判断の話ではない

→ 「今は振り返りシートで親子で振り返るのがいいと思います。また必要になったら、いつでもLINEください。」
