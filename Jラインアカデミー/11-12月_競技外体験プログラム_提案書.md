# Jラインアカデミー 11月・12月「競技外体験プログラム」実施のご提案

**宛先：** カターレ富山 強化部　遠藤部長／高橋俊太様
**作成：** 鈴木 崇文（2026年9月）

---

## 1. 背景：なぜ進め方を変えるのか

- Jラインアカデミーでは、選手向け研修と1on1の伴走を実施しています。
- 研修の一環として「競技以外のことを経験する場」を設ける予定です。
- **当初の計画**：選手との対話から「やりたいこと」を引き出し、選手自身が企画・運営するプロセスを弊社が伴走する。
- **現状**：チーム事情により、選手が一から企画を立ち上げて運営まで進める時間・余力の確保が難しい状況です。

➡ 当初のねらい（**選手の主体性を育てる／競技外の経験を積む**）は変えずに、**弊社が「選択肢」を用意し、選手が選んで主体的に取り組む形**に切り替えたいと考えています。

## 2. ご提案内容

- **実施回数**：11月・12月に各1回（計2回）
- **内容**：下記2つのプログラムを用意し、**どちらに参加するかは選手自身が選ぶ**

| | A. 営業同行 | B. スポGOMI リーダー |
|---|---|---|
| **概要** | 弊社の営業活動に同行し、商談の準備から実際の場までを体験する | 弊社共同代表・佐藤豪が取り組む「スポGOMI（スポーツごみ拾い）」で、選手がチームのリーダーを務める |
| **選手の役割** | 相手企業の事前調査、商談への同席、振り返り | チームメンバーのまとめ役、作戦（戦略）立案、当日の指揮 |
| **一緒に取り組む人** | 弊社メンバー、訪問先企業の方 | **ファン・サポーターの方々**（参加者を募集） |
| **得られること** | 社会・ビジネスの現場感覚、相手の立場で考える力、セカンドキャリアへの視野 | チームマネジメント・戦略立案の経験、ファンとの交流、地域貢献 |

## 3. クラブにとっての価値

- **選手の成長**：競技外の場で「考える・伝える・人を動かす」経験を積み、競技にも通じる主体性を養う
- **ファン・サポーターとの接点**（B）：選手とファンが同じチームで取り組むことで、応援する関係を超えたつながりが生まれる
- **地域への発信**：まちをきれいにする活動をクラブ・選手とファンが一緒に行う姿を発信できる

3. スポGOMIでのファン・サポーター募集方法（クラブ広報との連携可否）
4. その他、クラブとしてご懸念の点
