# Jラインアカデミー 11月・12月「競技外体験プログラム」実施のご提案

**宛先：** カターレ富山 強化部　遠藤部長／高橋俊太様
**作成：** 鈴木 崇文（2026年9月）

---

## 1. 背景：なぜ進め方を変えるのか

- Jラインアカデミーでは、選手向け研修と1on1の伴走を実施しており、その一環として「競技以外のことを経験する場」を設ける予定です。
- **当初の計画**：選手との対話から「やりたいこと」を引き出し、選手自身が企画・運営するプロセスを弊社が伴走する。
- **現状**：チーム事情により、選手が一から企画を立ち上げて運営まで進める時間・余力の確保が難しい状況です。

➡ ねらい（**主体性・考える力を育てる／競技外の経験を積む**）は変えずに、**弊社が2つの選択肢を用意し、選手が選んで主体的に取り組む形**に切り替えたいと考えています。

## 2. ご提案内容

- **実施回数**：11月・12月に各1回（計2回）
- **内容**：下記2つのプログラムから、**どちらに参加するかを選手自身が選ぶ**

| | A. スポンサー営業への同行 | B. スポGOMI リーダー |
|---|---|---|
| **概要** | クラブ社員のスポンサー営業に同行し、準備から商談の場までを体験する | 弊社共同代表・佐藤豪が取り組む「スポGOMI（スポーツごみ拾い）」で、選手がチームのリーダーを務める |
| **選手の役割** | 訪問先企業の事前調査、商談への同席、スポンサーの方との対話 | メンバーのまとめ役、作戦（戦略）立案、当日の指揮 |
| **一緒に取り組む人** | クラブの営業担当、スポンサー（候補）企業の方 | **ファン・サポーターの方々**（参加者を募集） |
| **得られること** | クラブ社員の仕事や、社員が外に伝えているクラブの価値、スポンサーの期待を知り、ピッチ上の結果の先につながる「期待」を自分ごとにする | チームマネジメント・戦略立案の経験／ファン・地域とのつながり／クラブの地域貢献の発信 |

## 3. 「やって終わり」にしない：学びを活かすサイクル

体験そのものより、**そこから何に気づき、どう競技・日常に活かすか**を重視します。体験の前後に振り返りシートを用意し、1on1の伴走と組み合わせて学びを定着させます。

| ステップ | 時期 | 内容 |
|---|---|---|
| ① 体験前シート | 実施1週間前 | 「何を知りたいか・何を試したいか」を選手自身が書き出し、問いを持って臨む |
| ② 体験 | 当日 | プログラムに参加 |
| ③ 体験後シート | 当日 | 「感じたこと・驚いたこと・自分に置き換えると」を記入し、体験前の問いと見比べる |
| ④ 1on1で深掘り | 1〜2週間以内 | 気づきを言葉にし、「競技・日常でどう活かすか」の具体的な行動を1つ決める |
| ⑤ 共有会 | 12月の研修内 | A・Bの参加者が互いに学びを発表し合う。違う体験から学び合う場にする |
| ⑥ 行動の確認 | 以降の1on1 | 決めた行動を実践できたかを確認し、次の一歩につなげる |

※ Aでは、選手からクラブ営業担当・スポンサーへ「学んだこと」を伝える機会（お礼のメッセージなど）もつくれると、社員・スポンサー双方にとっても価値のある場になると考えています。

| 時期 | 内容 |

## 5. ご相談したいこと

1. 11月・12月の実施可能な日程（練習・試合スケジュールとの兼ね合い）
2. 対象となる選手の範囲・人数
3. スポンサー営業同行について、営業部門へのご相談・同行先（スポンサー企業）の調整
4. スポGOMIでのファン・サポーター募集方法（クラブ広報との連携可否）
5. 共有会など、振り返りの場を研修内で確保できるか
