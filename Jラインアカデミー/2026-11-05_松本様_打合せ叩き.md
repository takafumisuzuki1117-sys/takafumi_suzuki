## 1. ご挨拶・大前提：JLINEアカデミーの目的（10分）

冒頭：お時間をいただいたお礼。高橋駿太様からご紹介いただいた経緯。

営業同行・スポGOMIの話に入る前に、「なぜこの取り組みをしているのか」を共有します。

### 1-1. プロジェクトの概要

- **名称**：カターレ富山 若手育成プロジェクト（JLINEアカデミー）
- **期間**：2026年2月〜2027年6月末（1.5シーズン）
- **対象**：1〜3年目の若手選手（現在8名程度）
- **始まり**：2025年3〜6月に、若手向けの講義（全6回）を実施しました。講義だけでは身についたとは言えない選手が多かったため、クラブから「時間がかかってもよいので一緒にやってほしい」とのお話をいただき、1年半かけて伴走する形になりました。
- 1/27のキックオフでは、高橋様から選手へ「社長の思いもあり、サッカー以外の部分を学んでもらうためにお願いした」とお伝えいただいています。

### 1-2. 選手にどうなってほしいか

**監督や戦術、チームが変わっても評価され続け、どこに行っても伸び続ける選手**になってほしいと考えています。

- 成長を決めるのは、能力よりも「考え方と取り組む姿勢」
- 技術だけでなく人として成長し、自分で成長を加速させられる
- 富山を離れても、同じように伸び続けられる（成長に再現性がある）

クラブとしては、そうした選手を育てられる **「育成の富山」の土台づくり**を目指しています。

### 1-3. クラブ（強化部）の考え

- **遠藤部長**
  - 分かっていなくても、行動を起こすことで初めて気づくことがある。座学よりも、行動する機会とアウトプットを増やしてほしい
  - 口出しせずに見守り、安心してトライできる環境にしたい
  - 普段の練習では、選手は用意されたメニューに取り組む側。自分たちで考える機会は貴重
  - いまは分からなくても、チャレンジしたことが数年後に「やってよかった」と思えればよい
- **高橋様**
  - 若手のうちに、支えてくれる人やお金の流れを知れば「サッカーだけやればいい」という考えが薄れ、同じ5年でも過ごし方が変わる
  - サッカー選手である前に一人の社会人として、こうした機会がないと得られない経験をしてほしい

### 1-4. 3つの柱と、競技外の取り組みの位置づけ

| 柱 | 内容 |
|---|---|
| ① 研修 | 自己分析、目標設定、メディア研修など。講義のあとにワークをして自分ごとにする |
| ② 個人伴走（1on1） | 月1回、目標を振り返り、次に取り組む課題を一緒に決める（PDCAを回す） |
| ③ 社会との接点 | 競技以外の経験をして、気づきを言葉にする　← **今回の営業同行・スポGOMIはここ** |

- 競技以外に取り組むのは、サッカーをおろそかにするためではありません。比重は100%サッカーに置いたまま、**視野と視座を広げて競技に活かす**ためです（若手 → ベテラン → 監督・コーチ → 社長と、見ている高さを上げていく）。

### 1-5. これまでの歩みと、選手の変化

| 時期 | 内容 |
|---|---|
| 2026/1/27 | キックオフ |
| 3〜6月 | 目標設定、月1回の1on1、メディア研修、シーズン振り返り面談 |
| 7月 | キャンプで、選手・監督・スタッフ全員でブラインドサッカー体験 |
| 9月〜 | 新シーズンの1on1 |
| 10/6・10/20 | 強化部と、競技外体験（営業同行・スポGOMI）の進め方を決定 |

- **選手の変化**：初回の1on1では「全試合出場」など、なりたい状態だけの目標でした。いまは選手自身が「ゴール＋アシスト10」と数字で目標を立て、残り試合数からペースを逆算するようになっています。
- 1on1は、チームの中では話しにくいことも言葉にして、頭を整理する場にもなっています。

### 1-6. 大前提から見た、今回の2つの取り組み

| | スポンサー営業同行 | スポGOMI |
|---|---|---|
| **形** | 選手が個別に参加（1社につき1〜2名） | 若手全員で参加するチーム企画 |
| **時期** | 年内に数件 | 2027年3月中旬〜4月 |
| **大前提とのつながり** | 支えてくれる人とお金の流れを知る。クラブやスポンサーが見ている高さを知り、視座を上げる | 企画の段階から自分たちで考え、行動して気づく。ファン・地域の方と一緒に取り組む |
| **狙い** | スポンサーの期待と、クラブが提供している価値を理解する | リーダーシップ・コミュニケーションを実践する |
| **競技にどう返るか** | 「ピッチ上の結果の先にある期待」を自分ごとにし、応援に応える意識が強くなる | 状況を見て作戦を修正する力、声で人を動かす力 |

- 営業同行については、遠藤部長からも「実際にクラブの事業に関わる機会なので、ぜひ実施させたい」とのお言葉をいただいています。

## 2. スポンサー営業同行（20分）

### 2-1. ねらい

選手に提案をつくってもらうのではなく、**スポンサーがクラブに何を期待しているか、それに対してクラブが何を提供しているか**を理解する場にしたいと考えています。

- 営業の現場で、スポンサーの期待と、クラブが提供している価値を選手が直接知る
- 「ピッチ上の結果の先に、どんな期待があるか」を自分ごとにし、競技への姿勢につなげる
- サッカー選手である前に一人の社会人として、ふだんは得られない経験を積む

### 2-2. 一連の流れ：「行って終わり」にしない

| ステップ | 時期（目安） | 内容 | 営業ご担当者にお願いしたいこと |
|---|---|---|---|
| ① 事前面談 | 訪問の7〜10日前 | 鈴木と選手で面談。「この同行で何を得たいか」を言葉にし、体験前シートに書く | なし |
| ② 企業研究と仮説づくり | 訪問の5〜7日前 | 選手が訪問先企業を調べ、仮説を持つ（下記）。鈴木がサポートする | なし |
| ③ 事前のすり合わせ | 訪問の2〜3日前 | 営業ご担当者から、今回の訪問の位置づけと当日の流れを共有いただく。選手は自分の仮説を伝える（15〜30分・オンライン可） | 訪問の流れの共有、選手の仮説へのひと言 |
| ④ 訪問（同行） | 当日 | 商談・訪問に同席し、仮説と実際を見比べる。終わったら体験後シートに記入する | 同行の受け入れ |
| ⑤ 振り返り | 訪問後1〜2週間 | 鈴木との1on1で、仮説とのずれや気づきを深掘りし、「競技・日常でどう活かすか」を1つ決める | （任意）選手へのフィードバックをひと言 |
| ⑥ 発表 | まとめて実施 | 学びを発表する場をつくる | （可能であれば）営業部の皆さまにもご参加いただきたい |

**②で選手に持ってもらいたい仮説**

- この企業の魅力・強みは何か
- この企業はいま何をしようとしているか（事業や地域での取り組みなど）
- この企業はクラブに何を期待していそうか。それに対して、クラブは何を提供しているか

- クラブの「夢先生」と同じスタンスで進めたいと考えています。準備を代わりにしていただくのではなく、選手が自分でやれるよう支えていただくイメージです。
- 選手との面談、シート、振り返り、発表の運営は弊社が担い、日々の営業のご負担にならないようにします。
- 選手からご担当者や訪問先へ「学んだこと」を伝える機会（お礼のメッセージなど）もつくりたいと考えています。

### 2-3. スケジュール感（案）：年内に2〜3件

**前提**

- 12/12が最終戦で、その後すぐオフに入り、1〜3月は選手が富山を離れます。年内に実施するなら12月上旬までが目安です。
- 練習・試合の日程や、冬場の体調管理との兼ね合いがあります。

**逆算すると**

| 時期 | 内容 |
|---|---|
| 〜11/13頃 | 営業側のご担当者を決め、同行先の候補と日程の目途を立てる |
| 11月中旬 | 同行する選手を決め、事前面談（①） |
| 11月下旬〜12月上旬 | 企業研究、事前のすり合わせ、同行（②〜④）。1件につき選手1〜2名 |
| 各訪問の1〜2週間後 | 振り返り（⑤） |
| 12月のオフ前、または年明けにオンライン | 発表（⑥） |

- 初回を11月下旬にする場合、11/13頃までに同行先と日程が決まっていると準備期間を確保できます。
- 年内に回り切れない選手は、選手が富山に戻ってから続ける形も考えられます。

### 2-4. 営業ご担当者に、どこまでお願いできるか

いちばん確認したいのはここです。理想は、営業ご担当者が事前に選手と話して営業の流れを共有し、選手の仮説を聞いていただくことです。日々の営業の中で、そこまでの時間を取れるかを伺いたいです。

| 関わり方 | 営業ご担当者にお願いすること | 目安の時間 |
|---|---|---|
| A. 事前に選手と話す | 訪問の流れを共有し、選手の仮説を聞いてひと言 → 当日の同行 | 事前30分＋当日 |
| B. 流れの共有だけ | 訪問の流れを共有する（仮説へのひと言は、当日の移動中などで） | 事前15分＋当日 |
| C. 当日の同行のみ | 当日の同行のみ。事前の流れは、鈴木がご担当者から伺って選手に伝える | 当日のみ |

- 訪問ごとに、A〜Cを選べる形でもよいと考えています。

### 2-5. ご相談・確認したいこと

1. 営業部門のご担当者（窓口）はどなたになるか
2. 上のA〜Cのうち、どこまでお願いできそうか
3. （できれば）同行の前に、参加する選手向けに「スポンサーがクラブに期待していること・クラブが提供していること」を話していただく場（20〜30分・オンライン可）を設けられるか
4. 同行に向いている訪問はどれか（既存スポンサーへの訪問、新規のご提案、契約更新、あいさつ回り など）
5. 年内の同行先の候補と件数
6. 年内の訪問予定のうち、選手が同行しやすい日時（練習後の午後 など）
7. 訪問先への事前のご説明を、どなたから、どのようにお伝えいただくか
8. 当日の決まりごと：同席する範囲、商談内容の守秘、服装、SNSなどでの発信の可否

## 3. スポGOMI（15分）

### 3-1. スポGOMIとは

- 日本財団スポGOMI連盟が展開している、ごみ拾いをスポーツにした競技です。
- 3〜5人で1チームを組み、決められたエリアで60分間ごみを拾います。ごみの種類ごとのポイントで順位を決めます（開会から表彰まで約3時間）。
- どこを狙うか、分別をどう進めるかをチームで作戦を立てるため、リーダーシップ・コミュニケーションの研修としても使われています。
- 詳しい内容は、弊社共同代表の佐藤豪から別途ご説明できます。

### 3-2. 現時点の想定（10/20の打合せより）

- **時期**：2027年3月中旬〜4月が目安（日程は強化部でご検討中）
- **参加**：若手選手と1月加入の新人で13〜14名。一般の参加者と選手を混ぜて、3人×4〜5チーム程度
- **事前研修**：リーダーシップ・コミュニケーションの研修（オンライン可）を行い、スポGOMIを実践の場にする
- **選手の関わり方**：人数・場所など、企画づくりの段階から選手に関わってもらう
- **遠藤部長のご意向**：営利目的にはしない。選手のインプットを増やす取り組みなので、「閉じすぎず、開きすぎず」の規模で設計する

### 3-3. 松本様にご相談したいこと

1. 営業（企画）の立場で関わっていただけるか。窓口はどなたになるか
2. 巻き込む先と規模感：スポンサー企業（社員の方の参加など）、行政、ファンクラブ、富山テレビ（スポGOMIワールドカップ富山大会の共催）などの候補のうち、どこまで広げるのが適切か
3. クラブの年間行事（ホームタウン活動・地域イベントなど）と時期が重ならないか。すでにある取り組みと組み合わせられるか
4. 参加者の募集・告知の方法と、対象の線引き（選手との交流が主な目的の方ばかりにならないよう、子ども中心・応募制なども検討中）
5. 準備の段取り：告知は少なくとも1か月以上前に行いたい。いつ頃までに日程・場所を確定するとよいか

## 想定問答（手元メモ）

- **Q. シーズン中に、競技以外のことをして大丈夫か？**
  → 比重は100%サッカーのままです。視野と視座を広げて競技に活かすための取り組みで、日程は強化部と相談し、練習・試合に影響しない形で行います。
- **Q. 選手が何か提案をするのか？**
  → 提案はしません。スポンサーがクラブに期待していることと、クラブが提供している価値を理解することが目的です。
- **Q. 営業の負担はどのくらいか？**
  → 関わり方はA〜C（2-4）から選べます。最小なら当日の同行だけです。面談・シート・振り返り・発表の運営は弊社が担います。
- **Q. 訪問先（スポンサー）にとってのメリットは？**
  → 選手と直接話せる機会になります。選手から学びやお礼を伝える場もつくり、関係づくりのきっかけにしていただけます。
- **Q. 商談の内容を選手に聞かせて大丈夫か？**
  → 同席する範囲は、事前に営業ご担当者と決めます。守秘については、事前面談で選手に伝えます。
- **Q. 費用はかかるのか？**
  → 【要確認】強化部との若手育成プロジェクトの範囲で実施する想定か、打合せ前に整理しておく。
